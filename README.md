## 故事與主要發現

我們用 PSFD 2007–2024 年 12 波、8,672 人的追蹤資料，先拆解幸福的組成，再檢驗「每個人有自己的權重」這個假設。

1. **家庭是幸福最大的來源**：工作、家庭、經濟、健康四個領域的滿意度可解釋幸福分數 40% 的差異，其中家庭分到 32%，健康、工作、經濟各約兩成。家庭生活「很不滿意」少 20.7 分，「很滿意」只多 7.5 分。
2. **而且越來越重**：家庭滿意度的標準化係數從 2007 年的 0.25 升到 2024 年的 0.32；控制年齡後仍成立，每個年齡層都上升。
3. **「你說你重視什麼」猜不到你的權重**：五個實驗（重要性直接當權重、重要性 × 滿意度、分群與潛在類別、個人隨機斜率、人生階段 × 滿意度）顯示，自評的重要性與態度只能解釋個人權重差異的 1.5% 以下，同一個人的權重隔幾年就會改變。
4. **真正改變配方的是人生階段**：沒有小孩時家庭權重約 0.51；最小孩子 6–17 歲的媽媽是 0.71，同階段的爸爸是 0.54。


## 方法摘要

- **幸福配方**：幸福 = β家庭·家庭滿意 + β工作·工作滿意 + β經濟·經濟滿意 + β健康·自評健康 + 控制變數（年齡、性別、調查年、填答方式），OLS 以人為群聚標準誤；Shapley 分解計算各領域占 R² 的比例。
- **個人權重**：家庭權重 w = β家庭 ÷（β家庭 + β工作），以交互作用、分群與潛在類別、隨機斜率、人生階段調節檢驗；個人化是否有用，以「用 2022 估計、預測同一批人 2024」判斷。
- **解讀與檢查**：個人固定效果、交叉延宕、事件研究；16 種替代設定、ordered logit、梯度提升樹。

工具：Python 3（pandas、numpy、scipy、statsmodels、linearmodels、scikit-learn、matplotlib、pyreadstat）。
